# Журнал изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] — 2026-09-26

Первый выпуск.

### Добавлено

- **IDE в браузере**: панели с изменяемыми размерами, редактор кода Monaco (диагностика компилятора inline и в панели «Проблемы», Cmd/Ctrl+S, Cmd/Ctrl+Enter), консоль, Serial Monitor, светлая и тёмная темы, интерфейс на русском через ключи перевода.
- **Редактор схемы**: добавление компонентов из каталога, перемещение, поворот, дублирование и удаление, ортогональные провода между выводами, сетка 2,54 мм с привязкой, отмена и повтор на уровне модели схемы.
- **Макетная плата** с реальной топологией: группы a–e и f–j, центральная канавка, отдельные шины питания.
- **Валидация схемы** (ошибки, предупреждения, сведения): замыкания шин, светодиод без резистора, плавающие входы, перегрузка GPIO, использование выводов UART/PWM и другие проверки на построенном netlist.
- **Изолированная компиляция** через arduino-cli 1.5.1 с зафиксированной платформой `arduino:avr` 1.8.8 и библиотекой Servo 1.3.0: отдельный контейнер без сети, лимиты ресурсов и времени, структурированная диагностика.
- **Эмулятор ATmega328P** на Rust: полный набор инструкций AVRe+, прерывания, GPIO, Timer0/1/2 и PWM, USART0, ADC; детерминированное время симуляции, conformance-тесты на реальных прошивках.
- **Электрическая модель**: DC-решатель рабочей точки схемы (выходы MCU, INPUT_PULLUP, резисторы, светодиоды, кнопки), предупреждения о перегрузке выводов.
- **Компоненты**: Arduino UNO R3, макетная плата, резистор, светодиод, кнопка, потенциометр, фоторезистор, RGB-светодиод, 7-сегментный индикатор, пьезоизлучатель, сервопривод — с документированной областью моделирования; примеры проектов.
- **Проекты**: хранение на сервере (PostgreSQL), автосохранение с оптимистичной блокировкой и разрешением конфликтов, история версий с просмотром и восстановлением.
- **Многопользовательский режим**: вход по паролю, роли студента, преподавателя и администратора, группы и коды приглашений, просмотр проектов студентов преподавателем только для чтения.
- **Развёртывание в контейнерах**: Docker Compose, nginx (SPA, прокси API и WebSocket, CSP), TLS с HTTP/2 и HSTS, необязательный basic auth, автоматические миграции.
- **Производительность**: число контейнеров сокращено (один сервис симуляции на все сессии), кэш результатов компиляции, ленивая загрузка редактора кода Monaco.
